HIGHLANDS HIKING TOURS — WEBSITE PROJECT

FILES
- index.html: home page
- tourist-destinations.html: destination information
- accommodation.html: accommodation types
- activities.html: hiking and related activities
- photo-gallery.html: illustrated gallery placeholders
- contact-booking.html: contact details and booking request form
- styles.css: shared design and responsive layout
- script.js: light/dark mode, mobile navigation, and demo form behaviour

HOW TO OPEN
1. Extract this ZIP file into a folder.
2. Keep all files together in the same folder.
3. Double-click index.html to open the website in a browser.
4. Use the navigation links to move between separate HTML pages.
5. Use the Light/Dark mode button to change the colour theme.

NOTES
This is a simple student project. The gallery uses CSS illustrations instead of photographs. Prices, providers, contact details, and availability are not verified. The booking form is a demonstration and does not send or store bookings.
